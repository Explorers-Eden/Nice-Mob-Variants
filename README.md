## 📖 Description
**Nice Mob Variants** introduces a variety of new mob variants, enhancing the game’s diversity and making encounters feel more vibrant. The data pack also adds two new blocks: the Livestock Breeder and the Frog Feeder.

## 🛠️ Technical Gibberish
This data pack double functions as the **required** resource pack. So simply slap that one also into your Resource folder and make sure to enable it in game for the textures to show properly.

_(This is not needed for the auto converted mod versions)_
